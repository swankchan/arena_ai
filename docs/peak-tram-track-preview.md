# Experimental full-length Peak Tram track

The standalone `tests/visual/peak-tram-track.html` renders paired 1.524 m-gauge rails, sleepers and track bed along both branches of the OSM trace. It is a **diagnostic preview, not the active game**, and does not contain actual road bridges, cuts, station approaches, switch hardware, vehicles or operating logic. Its translucent terrain is deliberately shown so buried or unsupported sections remain visible. It must not be mistaken for a finished railway.

`peak-tram-sample-profile.mjs` samples both branches at no more than 2 m along each OSM segment. Shared OSM nodes and common segments use shared variables. `peak-tram-joint-profile.py` uses numpy, scipy and OSQP to fit both routes simultaneously to DTM under sampled known-road elevation envelopes, a maximum gradient of tan(26°), an illustrative 0.012 per metre maximum change in grade, and the existing upper stub's estimated rail height. Curvature is a modelling choice, not an operating specification. `peak-tram-profile-data.js` is the checked-in result, not surveyed track. To reproduce, install numpy, scipy and osqp in a Python environment, then run `python3 tools/cities/hongkong/build-peak-tram-profile.py`; solver versions and tolerances can change numeric output. OSM trace © OpenStreetMap contributors, ODbL.

`node tools/cities/hongkong/check-peak-tram-joint-profile.mjs` checks the closest road query with a 1.65 m lateral margin. At present it reports 42 known crossing samples per branch, no violations beyond 1 mm numerical tolerance, and six unknown samples per branch. This is **not a clearance check**: only one nearest road is returned, the 6.3 m vertical envelope is hypothetical, and actual road/bridge meshes, other levels, swept carriage envelope and path continuity are not tested. The unknown crossing labelled 蒲魯賢徑 is not classified and is not constrained. The trial track is up to 7.87 m below or 8.19 m above current terrain; the cuts, retaining walls and bridge supports do not exist. The tentative lower rail height is about 39.22 m, not a real measured terminus elevation. Upper alignment still assumes an estimated existing station level and the current station is too narrow for the provisional car model.

Do not activate this geometry until a defensible road/rail and station design, terrain openings, bridge structures, clearance against actual geometry and game collision/traffic tests are completed. The standalone preview was visually checked using forced WebGL; the full game and WebGPU have not been verified.
