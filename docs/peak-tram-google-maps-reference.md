# Optional Google 3D Maps reference viewer

`tools/cities/hongkong/peak-tram-maps3d.html` is a separate manual reference tool, not part of the game. Serve it over HTTP and open it in a browser; enter a Google Maps Platform key there, then use the viewpoint buttons to inspect the vicinity of the Peak Tram. The viewer does not store the key in the repository, page URL or browser storage; the browser sends it to Google in the Maps JavaScript API script request. Reload clears the input. The key is visible in the browser's network requests, as is normal for browser API keys; restrict the key by website and API and enable billing / Maps JavaScript API as required. Loading maps can incur charges. Never commit a key. If a key has been exposed, rotate it.

[Google's 3D Maps documentation](https://developers.google.com/maps/documentation/javascript/3d/overview) describes the `maps3d` library, HYBRID mode and camera controls. Actual imagery, 3D coverage, freshness, accuracy and rendering depend on Google, network access, account configuration and the browser. The preset coordinates are approximate OSM route locations, not surveyed camera positions. Google imagery is not an engineering height profile. Do not download, cache or redistribute Google content without checking applicable Google Maps Platform terms and policies.

The sandbox could read the documentation through the page reader, but direct unauthenticated TLS connections to `maps.googleapis.com` and `maps.google.com` failed. The supplied key was not sent, so authentication, billing, 3D imagery coverage and map rendering have not been verified. The viewer is intended to allow a user with a working browser connection and correctly restricted key to perform that check; static tests are not proof that Google renders.
