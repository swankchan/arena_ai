# 入境事務大樓 Immigration Tower（灣仔舊址）

用戶確認指告士打道 7 號入境事務大樓，曾容納庫務署，並非隔鄰稅務大樓或長沙灣現時的庫務大樓。參考照片、權利提示和來源索引存於 [`references/hongkong/immigration-tower/`](../references/hongkong/immigration-tower/README.md)。

主樓輪廓採 OSM way 510722228 v8（© OpenStreetMap contributors，ODbL）；其 Wikipedia／Commons 標籤錯誤指向終審法院，不予採用。模型採 180.8m／49 層的 CTBUH 資料，OSM 標籤則記 180m／50 層。深藍灰玻璃、細密銀灰格框、黑色粗框及深色底座按照片塑造；窗行、框數及大堂雨篷尺寸為照片導向估算，並非施工圖。夜間部分窗格使用隨日夜變化的暖色自發光，開燈位置屬示意，不代表實際租戶或亮燈時段；未憑空添加不確定的屋頂廣告。官方記載該大樓參與幻彩詠香江的是屋頂 LED 螢幕，現在未重現該螢幕。

模型以中心的 DTM 高度約 5m 為基準，外牆腳及雨篷柱腳取局部地形；**並非實測樓面標高**。OSM 入口節點設近似 4.8m 寬開口及淨高 5m 的牆段，入口後方尚無完整大堂或天橋接駁。周邊道路 5,893 個一米格採樣、4.8m 車高的 collider 檢查零命中；此為離散測試，不代表完整連續路面、天橋、行人或駕駛驗證。地形未被改平，相關地台、告士打道花園、出入口及與鄰樓的步道仍需實景及道路高度校正。模型未在完整遊戲或 WebGPU 實測，不能當作已目視驗收。
