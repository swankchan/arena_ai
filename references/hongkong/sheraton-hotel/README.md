## Lighting/serialization audit
The hotel previously assigned TSL nodes to ordinary MeshStandardMaterial objects. The vendored WebGPU renderer copies those properties when compiling, but ordinary Three.js material JSON does not serialize the attached nodes. The hotel now uses explicit MeshStandardNodeMaterial locally for the palette's node-driven surfaces, windows, canopy lights, pool water and signs. Guestroom emission is warm and controlled by the shared night uniform; the choice of lit rooms and intensity are visual approximations. This does not change shared palette functions or the building footprint. The ordinary Editor export still intentionally simplifies node materials and cannot reproduce dynamic night lighting; the TSL export retains nodes, but the Editor's ordinary ObjectLoader does not support them.
