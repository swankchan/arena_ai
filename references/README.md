# Asset research references

Keep reference material by place and subject, for example `hongkong/the-murray/`. Each folder should include an index naming every retained file, its source page, provenance/credit where known, date accessed, and what it is useful for. Keep research notes and measurements separately from original sources, identify estimates, and do not present a rendering as a photograph.

Reference images and documents belong to their respective rights holders unless a licence says otherwise. They are reference material, **not** game assets or permission to redistribute or reuse. Check the applicable rights before redistributing them or using them in a runtime asset. Avoid official Slop Hong Kong assets. Do not silently overwrite a previously saved reference; if a source changes, document the new version and date.
